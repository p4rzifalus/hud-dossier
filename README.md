# HUD Dossier — генератор постеров

Веб-инструмент, который превращает картинку в постер в эстетике «научного досье / HUD сканера»:
монохромная палитра, свечение, зерно и рамка из панелей с графиками, вычисленными из самой картинки.

Всё работает в браузере, картинки никуда не загружаются.

**Открыть:** https://p4rzifalus.github.io/hud-dossier/

Локально: скачать репозиторий и открыть `index.html` двойным кликом.

Шрифт — IBM Plex Mono (SIL Open Font License 1.1), встроен в `js/font-data.js`.
