# HUD Dossier — генератор постеров

Веб-инструмент, который превращает картинку, видео или изображение с камеры в постер в эстетике «научного досье / HUD сканера»: монохромная палитра, свечение, зерно и рамка из панелей с графиками, вычисленными из самого изображения.

Всё работает в браузере, файлы никуда не загружаются.

**Открыть:** https://p4rzifalus.github.io/hud-dossier/

## Что умеет

- **Картинка** — постер, экспорт PNG 1x/2x/4x и SVG (рамка и текст векторные).
- **Видео** (mp4, webm, mov) — живое превью с эффектом на видеокарте, плеер с отрезком «начало — конец», стоп-кадр в PNG.
  - Панели считаются из каждого кадра со сглаживанием, рамки увеличения плавно следят за деталями, интерфейс анимирован (выкл / спокойно / активно).
  - Экспорт видео покадрово в полном качестве: MP4 (H.264) или WebM, 720p / 1080p / как исходник, 24/30 fps, звук по желанию.
  - Экспорт GIF: до 800 px, 12/15 fps, до 8 секунд, палитра из цветов эффекта, вес показывается заранее.
- **Камера** — живое превью, выбор камеры (фронтальная / основная), «снять фото» → дальше как с картинкой, запись: обработанный ролик сохраняется сразу, а исходник открывается как видео для экспорта в полном качестве.

## Как запустить

- **Картинки и видео:** двойной клик по `index.html`.
- **Камера** работает только по https или с localhost:
  - на компьютере — двойной клик по `start.command` (откроет http://localhost:8765), или просто ссылка на сайт выше;
  - на телефоне — открыть https://p4rzifalus.github.io/hud-dossier/ (адрес вида 192.168.x.x по Wi-Fi камеру не пустит).

## Поддержка браузеров

| | Chrome / Edge | Safari | Firefox |
|---|---|---|---|
| Картинки, PNG, SVG | да | да | да |
| Видео: превью с эффектом | да | 15+ | да |
| Экспорт MP4 | да | 16.4+ | 130+ (может выйти WebM) |
| Звук в экспорте | да | только новые версии | да |
| GIF | да | да | да |
| Камера и запись | да | да (запись в MP4) | да (запись в WebM) |
| `.mov` с кодеком HEVC | зависит от системы | да | нет |

Проверено автоматически в Chromium. Safari и телефоны — по чек-листу вручную.
