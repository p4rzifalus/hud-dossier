# HUD Generator — инструкция для Claude

Веб-инструмент: картинка, видео или камера → постер в эстетике «научного досье / HUD». Что умеет и как пользоваться, описано в README.md.

Пользователь — дизайнер, не разработчик. Объясняй простыми словами и сам выполняй команды.

## Устройство

- Чистая статика без сборки и без npm. Файлы из `js/` подключаются обычными `<script>` в конце `index.html`, **порядок важен**: следующий файл пользуется глобальными функциями предыдущих. Новый файл добавляй в нужное место этого списка.
- Публикация: GitHub Pages из ветки `main`, корень репозитория (`p4rzifalus/hud-dossier`). `.nojekyll` нужен, чтобы Pages отдавал файлы как есть. После `git push` сайт обновляется сам за минуту-две.
- Всё работает в браузере, файлы пользователя никуда не уходят. Сохраняй это свойство: никаких запросов к внешним серверам с данными пользователя.

## Модули (`js/`)

| Файл | За что отвечает |
|---|---|
| `rng.js` | Случайные числа от seed: одинаковый seed → одинаковый постер |
| `palette.js` | Палитры: 5 цветов от тёмного к светлому |
| `image-process.js` | Обработка картинки на процессоре: контраст → зерно → дизеринг → палитра |
| `gl-process.js` | Та же обработка на видеокарте (WebGL2) для видео и камеры. Математика должна совпадать с `image-process.js` |
| `analysis.js` | Анализ картинки: всё, что панели показывают «про эту картинку» |
| `textgen.js` | Псевдонаучный текст для панелей |
| `draw.js` | Общие команды рисования. Одни и те же вызовы рисуют в Canvas и в SVG |
| `layout.js` | Раскладка постера по зонам (шапка / лево / право / низ / центр) |
| `panels.js` | Генераторы панелей и сборка интерфейсного слоя |
| `render.js` | Сборка постера из слоёв, пересчёт только изменившихся |
| `video-source.js`, `live.js` | Видео: плеер, точная перемотка; отрисовка движущегося источника |
| `camera.js` | Камера: превью, выбор камеры, снимок, запись |
| `export.js` | Экспорт PNG/SVG в нужном размере |
| `export-video.js`, `export-gif.js` | Покадровый экспорт MP4/WebM и GIF |
| `ui.js` | Интерфейс: панели настроек, кнопки, связка всего вместе |
| `font-data.js` | Встроенный шрифт IBM Plex Mono для SVG-экспорта |
| `vendor/` | Чужие библиотеки: `mediabunny` (видео), `gifenc` (GIF). Не правь их |

Остальное: `css/style.css` — вся вёрстка, `fonts/` — шрифт интерфейса TikTok Sans, `assets/icons/` — иконки интерфейса.

## Проверка

- Локальный сервер: превью «hud» из `.claude/launch.json` (http://localhost:8765) или `start.command`. Камера работает только на localhost или https.
- `_test/` — тестовые картинки и видео. Папка в `.gitignore`, на GitHub не уходит.
- Проверяй в Chrome и, если правка касается видео или экспорта, учитывай таблицу браузеров в README.md.
- Камеру на компьютере проверить можно, но мобильную камеру — только на телефоне через опубликованный сайт. Честно говори, что проверено, а что нет.
